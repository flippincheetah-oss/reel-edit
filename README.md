# Reel Edit (Claude skill)

A skill (a saved instruction file Claude follows) that turns your approved clips plus a voiceover into a ready-to-post vertical Reel, TikTok, or Short, with the same look every time. It is a blank slate that works for any niche.

## What it does
- Interviews you first (voiceover, hook text, clips, length)
- Fixes phone HDR video so colors match the original, with no filters
- Adds a hook and word-by-word captions in app-safe zones
- Exports one 1080x1920 file for Instagram, TikTok, YouTube Shorts, and Facebook

## How to use
1. Copy `SKILL.md` into your Claude skills folder.
2. Fill in "Your Style Settings" and the example Clip Library at the bottom.
3. Ask Claude to edit a Reel.

No footage, personal data, or keys are included.
